# Hostel-management
Roomify is a hotel management system 
that can be used by students living in the hostel and the 
hostel manager.

The functionalities provided for each are:

1)Student

-Sign Up

-Login

-View profile 

-View services 

-View Room details

2)Manager

-Allocate room

-Delete students

-Add room

-Delete room

-View Services

-Login
